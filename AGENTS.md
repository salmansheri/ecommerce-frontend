# AGENTS.md

## Stack

React 19 + TypeScript + Vite + TanStack Start/Router + Tailwind CSS v4 + shadcn/ui + Netlify

Package manager: `pnpm`. Path alias: `@/*` → `src/*`.

## Commands

- Install: `pnpm install`
- Dev server (port 3000): `pnpm dev`
- Build: `pnpm build`
- Preview: `pnpm preview`
- Biome: `pnpm lint` / `pnpm format` / `pnpm check`
- Tests: `pnpm test` (Vitest, no config file; use `--passWithNoTests` if no tests exist yet)

## Quality Gate Order

1. `pnpm check`
2. `pnpm test`
3. `pnpm build`

## Generated / Codegen Files

- `src/routeTree.gen.ts` - auto-generated by TanStack Router. Do not edit.
- `src/generated/*` - auto-generated from OpenAPI spec (`hey-api/openapi.json`) via `pnpm openapi-ts`. Regenerate with that command.
- Biome is configured to ignore `routeTree.gen.ts` and `styles.css`.

## State Management

- Cart (`src/lib/cart-store.ts`): uses `@tanstack/store` (Store, Derived).
- Auth (`src/lib/auth-store.ts`): uses `zustand` with persist.
- Header rendered in `src/routes/__root.tsx` shell (outside route transitions).

## Deployment

Configured for Netlify (`netlify.toml`): build outputs to `dist/client`.

## Shadcn Components

Add components with: `pnpm dlx shadcn@latest add <component>`
